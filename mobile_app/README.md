# Plant Care Mobile App

Flutter mobile interface for the Automated IoT Indoor Plant Monitoring System.

## Run

From this directory, run:

```bash
flutter pub get
flutter run
```

The current overview uses sample readings. The ESP32, backend, AI service, and real pump control are not connected. The Water button is only a local demo interaction.

## Current preview

- Plant overview and connection status
- Soil moisture, temperature, humidity, and light cards
- Sample care insight and recent activity
- Demo watering control with an explicit hardware-disconnected notice
- Overview, My plants, Plant AI, and Settings navigation
